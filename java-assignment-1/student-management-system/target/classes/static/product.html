THE PROJECT

Student information,
thoughtfully organised.

StudentHub is a simple academic website presenting the concept of a Student Management System.

In an educational environment, information can become scattered across forms, files, and spreadsheets. A student management application can bring common tasks into a more organised workflow. This assignment introduces that idea through a five-page website.

01

Purpose

Explain how student details and academic information could be organised and accessed more conveniently.

02

Technologies used

Java and Spring Boot serve the website, while HTML and CSS provide the page structure and visual design.

JavaSpring BootSpring WebHTMLCSS
03

Target users

The concept is intended for educational environments where student information is relevant.
